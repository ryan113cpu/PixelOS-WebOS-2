PixelOS WebOS 2
PixelOS WebOS 2 is a web-based operating system that runs in your browser.
I started this project because I wanted to see how far I could push a browser into feeling like an actual operating system. It's not meant to replace a real OS, but it's designed to feel like one.
About
PixelOS has a desktop, apps, windows, settings, and other features you'd normally expect from a basic operating system.
The project is still being worked on, so some parts may be unfinished or have bugs.
Features
Desktop environment
App system
Window management
Built-in browser
Settings
Search
Clock
File interfaces
Custom UI
Various system tools
More features will be added as development continues.
Built With
HTML
CSS
JavaScript
PixelOS doesn't need to be installed. It runs directly in a supported web browser.
Development
This project is still actively being worked on.
Some features may change, break, or get completely replaced as PixelOS develops. That's part of the project.
Bugs
If you find a bug, feel free to report it.
Things like broken apps, buttons that don't work, loading problems, visual bugs, or anything else unusual are useful to know about.
